# Inc-5000-Companies-Data-Analysis
This project performs an end-to-end analysis of the Inc. 5000 dataset, focusing on identifying growth trends, revenue distribution, and operational efficiency across industries and regions. The workflow includes data cleaning, SQL-based analysis, and an interactive dashboard for business insights.
